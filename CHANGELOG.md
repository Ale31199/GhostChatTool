# Changelog

All notable changes to GhostChatTool are documented here.

## [1.0.0] - 2026-09-03

### Added

- Interactive selection of recent non-Project ChatGPT conversations.
- Exact `thread_id` targeting.
- `DELETE` confirmation before any mutation.
- Automatic timestamped SQLite backup.
- Best-effort check that the ChatGPT Windows app is closed.
- Database integrity verification with `PRAGMA integrity_check`.
- Safety stop unless exactly one local catalog row is deleted.
- `--help`.
- `--version`.
- `--list`.
- `--limit`.
- `--id`.
- Installer and uninstaller for the `ghostchat` command.
- MIT license.
- Security and privacy documentation.
