# GhostChatTool / GhostChat Sync Fix v2.2.0

Windows workaround for stale or deleted ChatGPT Desktop conversations that remain in **Recents** after deletion from another device.

The project contains:

- the original/manual GhostChat cleanup flow;
- a conservative background watcher;
- **Smart Restart (`ChatGPT - Sync & Fix`)** for forcing the Desktop app to perform the strong sync that testing showed is needed before some remote deletions become visible locally.

See `PATCH_README.md` for the v2.2 workflow and safety rules.
